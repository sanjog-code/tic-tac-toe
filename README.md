# Tic Tac Toe

A classic Tic-Tac-Toe console game implemented in C and C++.

## Features
- **C Implementation (`v1ttt.c`)**: Original console-based Dev-C++ project with bot opponent and randomized turn logic.
- **Modern C++ Implementation (`main.cpp`)**: Object-oriented implementation with win/tie detection, input validation, and clean board display.
- **Dev-C++ Support**: Includes project configuration (`Tic Tac Toe.dev`).

## How to Compile & Run

### Using GCC / G++ (Command Line)
```bash
# Compile and run the C++ version:
g++ -O2 -o tictactoe main.cpp
./tictactoe

# Compile and run the C version:
gcc -o v1ttt v1ttt.c
./v1ttt
```

### Using Dev-C++ IDE
1. Open `Tic Tac Toe.dev` in Dev-C++.
2. Click **Execute -> Compile & Run** (F11).
